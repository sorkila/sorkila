# Angles: a wide pass of concepts to pick from (2026-10-27)

Same lore as prompts.md (Sólhvarf, Gjenfødt, Mørketid / Solverv, Simpløyer MMXXVI), same rules (sun is a disc, one unreadable thing per shirt, no banned symbols). Four angles: synthwave, epic, the Satisfy Running look, and a few outside the metal frame. One prompt per concept, rendered once for the pick, then iterated. Spelling note: never name a wrong letter in a prompt (saying "not Ø" produced Ø twice).
